    Sobre este geoportal

    Consulta de la base geoespacial del sistema de drenaje mixto del Casco Viejo de Oruro (364,9 ha), elaborada en el proyecto de grado Diagnóstico geoespacial del sistema de drenaje mixto urbano del Casco Viejo de Oruro mediante SIG para la gestión territorial del riesgo de inundaciones (Carrera de Ingeniería Geográfica, UMSA).

    Datos

    Relevamiento de campo
    05/07/2025 – 23/07/2025, con QField y formularios digitales
    Elevaciones
    Modelo Digital de Superficie fotogramétrico (10 cm/píxel); alturas elipsoidales
    Base de datos
    PostgreSQL/PostGIS, depurada y validada mediante un proceso reproducible
    Sistema de referencia
    WGS 84 / UTM zona 19S (EPSG:32719)

    Nivel de certeza

    Confirmado
    Observado o medido directamente.
    Probable
    Localizado, con atributos observados desde la superficie.
    Inferido
    Estimado a partir de evidencia indirecta (por ejemplo, el trazado enterrado de una tubería).
    No determinado
    Información insuficiente.

    Notas de interpretación

    • Las tuberías inferidas o no determinadas se dibujan con línea discontinua; los trazos blancos animados muestran el sentido del flujo.
    • La pendiente de las tuberías (%) se calcula en el sentido del flujo con las cotas de fondo: elevación del terreno (MDS) menos la profundidad medida en campo. Sin profundidades, en las tuberías de cámaras se usa el terreno entre cámaras. Un valor negativo indica contrapendiente.
    • Las alturas del MDS son elipsoidales; las pendientes dependen solo de las diferencias de altura.
    • La base se edita desde QGIS o desde este geoportal (usuarios autorizados, con «Iniciar sesión»); cada cambio guardado se refleja aquí en pocos segundos y queda en el historial de ediciones.
    • Las secciones de canal estimadas no fueron medidas directamente.
